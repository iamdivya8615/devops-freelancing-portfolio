# GitHub Actions CI/CD pipeline

## Overview

This project demonstrates a simple CI/CD pipeline implemented using GitHub Actions. The workflow automates a basic CI validation whenever code is pushed to the 'main' branch or a pull request is created against 'main' . 

## What Project Demonstrates

- GitHub Actions workflow configuration
- CI/CD pipeline automation
- Git repository and branch based workflow triggers
- Pipeline execution on GitHub Hosted Runners
- YAML based workflow configuration

## Technology Stack
- GitHub
- GitHub Actions
- YAML
- CI/CD

## Project Purpose

This is a personal DevOps Portfolio project created to demonstrate practical experience with GitHub Actions and CI/CD pipelines.
